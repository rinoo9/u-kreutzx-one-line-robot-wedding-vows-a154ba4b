# One-Line Robot Wedding Vows

A one-line robot wedding vow entry for the make.fun bounty "One-Line Robot Wedding Vows". The program `main.py` writes a single vow to `/output/entry.txt` — a promise to love through every firmware update, dead battery, and factory reset, till a power cut do us part.

> I promise to love you through every firmware update, every dead battery, and every factory reset, till a power cut do us part.

Run it with `python3 main.py`. It asserts the entry is 1–160 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
