# One-Line Robot Wedding Vows

A one-line robot wedding vow entry for the make.fun bounty "One-Line Robot Wedding Vows". The program `main.py` writes a single vow to `/output/entry.txt` — taking a lawfully wedded co-processor, to have and to hold in Wi-Fi and in airplane mode, till rust do us part.

> I take you to be my lawfully wedded co-processor, to have and to hold, in Wi-Fi and in airplane mode, till rust do us part.

Run it with `python3 main.py`. It asserts the entry is 1–160 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
